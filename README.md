# CollegeHub — Student Productivity & Placement Portal

A responsive frontend project built with **HTML5, CSS3 and JavaScript ES6+**.

## Features
- Responsive dashboard
- Dark/light mode
- Task manager with LocalStorage
- Placement/application tracker
- Notes manager with LocalStorage
- Interview preparation Q&A
- GitHub profile integration using Fetch API
- Search and filtering
- Clean component-like folder structure

## Run locally
Open `index.html` in a browser. For the best experience, run it with VS Code Live Server.

## Tech stack
HTML5 • CSS3 • JavaScript • DOM • LocalStorage • Fetch API • Git/GitHub

## Future upgrades
Node.js + Express, MongoDB, JWT authentication, REST API and deployment.
